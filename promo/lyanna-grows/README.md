# লিয়ানা বড় হচ্ছে (হোম পাতার অ্যানিমেশন)

ছোট্ট লিয়ানা চার ধাপে বড় হয়ে চাকরিজীবী হয়: শিশু, স্কুল, প্রস্তুতি, চাকরি। প্রতিটি ভিডিওর শেষের অ্যানিমেশনের সঙ্গে একই চরিত্র।

- ফাইল: `lyanna-grows.js` (প্রায় ১০ KB, gzip-এ সাড়ে ৩ KB)। কোনো ছবি, ফন্ট বা শব্দ-ফাইল লাগে না।
- নমুনা: `/promo/lyanna-grows/`
- পর্দায় এলে একবার চলে (৩.৭ সেকেন্ড), তারপর থেমে থাকে আর মাঝে মাঝে চোখ পিটপিট করে। চাপলে আবার চলে।
- যাঁরা ফোনে "কম নড়াচড়া" চালু রাখেন, তাঁরা সরাসরি শেষ ছবিটা দেখেন।
- সাইটে কোনো শব্দ নেই। শব্দ শুধু ভিডিওতে।

## হোম পাতায় বসানো (LY Site-এর কাজ)

১. `index.html`-এর `#lyanna` অংশে, "এই প্রকাশনী তার নামে।" লেখার `</p>`-এর ঠিক পরে:

```html
<lyanna-grows style="margin:18px auto 4px"></lyanna-grows>
<p class="lg-cap">লিয়ানা বড় হচ্ছে, পাশে থাকছে প্রস্তুতিও</p>
```

২. পাতার শেষে, `</body>`-এর আগে:

```html
<script src="/promo/lyanna-grows/lyanna-grows.js" defer></script>
```

৩. `.lg-cap`-এর মাপ সাইটের নকশা অনুযায়ী ছোট আর হালকা রঙে (প্রায় ১৪-১৫px, মাঝখানে)।
