শুধু অ্যাডমিনের জন্য। সব উৎস থেকে একটা টপিকের অংশ খুঁজে বাছাই করুন, তারপর একসাথে Markdown হিসেবে নামান।

সংশ্লিষ্ট এমসিকিউ

সাইটের প্রশ্নব্যাংক (বিসিএস, চাকরি, চলমান, অধ্যায়) থেকে একই শব্দ মেলে এমন প্রশ্ন। টিক দিলে এক্সপোর্টে লিখিত অংশের পরে যাবে।

নতুন অংশ তোলা

CSV বা JSON ফাইল থেকে তুলুন

ফাইলে প্রতিটি অংশে id আর text লাগবে; বাকি ঘর (subject, exam, chapter, chapter_title, section_no, section_title, parent_section, kind, tags, pages, source) থাকলে ভালো। একই id আবার তুললে আগেরটা হালনাগাদ হয়, ডুপ্লিকেট হয় না।

এমসিকিউ ব্যাংক ও টপিক তালিকা খোলা

Lyanna_data থেকে বানানো library-mcq.json.gz ফাইলটা দিন (কম্পিউটার থেকে দেওয়া ভালো, ফাইলটা বড়)। ফাইলটা সার্ভারে যায় না: এই ব্রাউজারেই রাখা থাকে আর এখানেই খোঁজা হয়, তাই D1-এ কিছু লেখা হয় না। নতুন এক্সপোর্ট বানালে আবার দিন।
