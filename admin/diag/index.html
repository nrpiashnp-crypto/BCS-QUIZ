All answers CSV

All parts are open for testers right away, with no wait for dates or earlier tests. Their results are not counted in standing or attendance. Before you add an e-mail, that person must log in to the site once with Google.

Clean up after testing

This deletes all testers' marks, night feedback and notes so they can start over. Nobody else's data is touched.

Keep the original copy of whatever you upload in Lyanna_data at pilot/custom-plan/<set>.json (D1 has no backup of its own). Format: PLAN.md §9 there.



Automatic upload (upload key)


When a set is merged into pilot/custom-plan/sets/ in Lyanna_data, GitHub uploads it here by itself. For that, this key must be stored in BCS-QUIZ's secrets as LY_UPLOAD_KEY. The key can only upload sets and questions. Making a new one cancels the old one.

Teacher's weekly export (export key)


Every Monday morning Lyanna_data pulls last week's marks, feedback and change log into feedback/ by itself (LY Teacher reads it). No names or e-mails go in. For that, this key must be stored in Lyanna_data's secrets as LY_EXPORT_KEY. The key is read-only. Making a new one cancels the old one.
