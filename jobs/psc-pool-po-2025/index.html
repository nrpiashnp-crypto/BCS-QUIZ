  1. ১. কোনো গ্রামের জনসংখ্যা ৮% বৃদ্ধি পাওয়ায় ২১,৬০০ জন হলো। পূর্বে ঐ গ্রামের জনসংখ্যা কত ছিলো?
    • ক. ১৮,৩৬০ জন
    • খ. ১৮,৫০০ জন
    • গ. ১৯,০০০ জন
    • ঘ. ২০,০০০ জন
    উত্তর: ঘ. ২০,০০০ জন
    পূর্বের জনসংখ্যা 100 ধরলে 8% বৃদ্ধির পর হয় 108। শতকরা বৃদ্ধির সমস্যায় এই অনুপাত ধরেই এগোনো সবচেয়ে সহজ।
    108 হলে পূর্বে ছিল 100
    21600 হলে পূর্বে ছিল (100 × 21600) / 108 = 20000 জন।
    যাচাই: 20000-এর 8% = 1600, আর 20000 + 1600 = 21600।
    মনে রাখুন: শতকরা বৃদ্ধি হলে পূর্বের মান = নতুন মান × 100 / (100 + বৃদ্ধির হার)। শতকরা হ্রাস হলে হর হবে (100 − হ্রাসের হার)।
  2. ৩. x² − x − 12 = 0 এর মূলদ্বয় নিচের কোনটি?
    • ক. −3, −4
    • খ. 3, −4
    • গ. −3, 4
    • ঘ. 3, 4
    উত্তর: গ. −3, 4
    x² - x - 12 = 0 সমীকরণটি উৎপাদকে ভাঙি।
    x² - 4x + 3x - 12 = 0
    বা, x(x - 4) + 3(x - 4) = 0
    বা, (x - 4)(x + 3) = 0
    অতএব x = 4 অথবা x = -3। মূলদ্বয় -3 ও 4।
    মনে রাখুন: মূলদ্বয়ের যোগফল = -(x-এর সহগ) = 1, আর গুণফল = ধ্রুবক পদ = -12। 4 + (-3) = 1 এবং 4 × (-3) = -12 মিলে যায়।
  3. ৪. 4^(x+1) = 32 হলে, x এর মান কত?
    • ক. 3/2
    • খ. 5/2
    • গ. 3
    • ঘ. 5
    উত্তর: ক. 3/2
    32 = 2⁵ এবং 4 = 2², তাই 4^(x+1) = (2²)^(x+1) = 2^(2x+2)।
    সমীকরণ হলো 2^(2x+2) = 2⁵
    অতএব 2x + 2 = 5
    বা, 2x = 3
    বা, x = 3/2।
    মনে রাখুন: ভিত্তি একই হলে ঘাত সমান ধরতে হয়। প্রথমে সব সংখ্যাকে এক ভিত্তিতে লিখে নেওয়াই কৌশল। এখানে (a^m)^n = a^(mn) সূত্রটি কাজে লেগেছে।
  4. ৮. a − b, a² − ab, a² − b² এর ল.সা.গু. নিচের কোনটি?
    • ক. a−b
    • খ. a²−b²
    • গ. a(a−b)
    • ঘ. a(a²−b²)
    উত্তর: ঘ. a(a²−b²)
    একাধিক রাশির ল.সা.গু. বের করতে হলে প্রথমে প্রতিটি রাশিকে উৎপাদকে ভাঙতে হয়:
    a - b = (a - b)
    a² - ab = a(a - b)
    a² - b² = (a + b)(a - b)
    সবগুলোর ল.সা.গু. = a(a + b)(a - b) = a(a² - b²)।
    মনে রাখুন: ল.সা.গু.-তে প্রতিটি উৎপাদক সর্বোচ্চ ঘাতে নিতে হয়, আর গ.সা.গু.-তে সাধারণ উৎপাদক সর্বনিম্ন ঘাতে। দুটি রাশির ল.সা.গু. × গ.সা.গু. = রাশি দুটির গুণফল।
  5. ১৩. 3a²b⁴c³, 12a³b²c, 6a⁴bc² এর গ.সা.গু. নিচের কোনটি?
    • ক. 3a²bc
    • খ. 3a²b²c²
    • গ. 12abc
    • ঘ. 3abc
    উত্তর: ক. 3a²bc
    গ.সা.গু. বের করতে সংখ্যাগুলো ও চলকগুলো আলাদা করে দেখি।
    সংখ্যা অংশ: 3, 12, 6-এর গ.সা.গু. = 3।
    চলক অংশ: a-এর ক্ষুদ্রতম ঘাত 2, b-এর ক্ষুদ্রতম ঘাত 1, c-এর ক্ষুদ্রতম ঘাত 1।
    তাই গ.সা.গু. = 3a²bc।
    মনে রাখুন: গ.সা.গু.-তে সাধারণ উৎপাদকের সর্বনিম্ন ঘাত নিতে হয়, আর ল.সা.গু.-তে সর্বোচ্চ ঘাত। এই রাশিগুলোর ল.সা.গু. হতো 12a⁴b⁴c³।
  6. ১৪. π (পাই) = ?
    • ক. 3.1416
    • খ. 180°
    • গ. উভয়টিই
    • ঘ. একটিও না
    উত্তর: গ. উভয়টিই
    π (পাই) একটি ধ্রুবক সংখ্যা। বৃত্তের পরিধিকে তার ব্যাস দিয়ে ভাগ করলে সব বৃত্তেই একই মান পাওয়া যায়, সেটিই π। এর আসন্ন মান 3.1416 (বা ভগ্নাংশে প্রায় 22/7)। আবার কোণের মাপে π রেডিয়ান = 180°। তাই দুটি উক্তিই ঠিক, এবং সঠিক উত্তর ‘উভয়টিই’।
    মনে রাখুন:
    π রেডিয়ান = 180°
    2π রেডিয়ান = 360°
    π একটি অমূলদ সংখ্যা, তাই এর দশমিক কখনো শেষ হয় না।
  7. ১৮. x² − 9 ≤ 0 এর সমাধান কোনটি?
    • ক. −3 < x < 3
    • খ. −3 ≤ x < 3
    • গ. −3 ≤ x ≤ 3
    • ঘ. −3 < x ≤ 3
    উত্তর: গ. −3 ≤ x ≤ 3
    x² - 9 ≤ 0 অসমতাকে উৎপাদকে ভাঙি: (x + 3)(x - 3) ≤ 0।
    দুটি উৎপাদকের গুণফল শূন্য বা ঋণাত্মক হবে যদি x, -3 ও 3-এর মধ্যে থাকে বা তাদের সমান হয়। কারণ দুটি উৎপাদকের একটি ঋণাত্মক এবং অন্যটি ধনাত্মক হতে হবে।
    অতএব -3 ≤ x ≤ 3।
    মনে রাখুন: ≤ চিহ্ন থাকলে প্রান্তবিন্দু দুটি সমাধানের অন্তর্ভুক্ত হয়, আর < থাকলে হয় না। তাই এখানে -3 ও 3 দুটিই সমাধানের অংশ।
  8. ১৯. একটি বর্গের পরিসীমা 36 মিটার হলে এর একটি কর্ণের দৈর্ঘ্য কত?
    • ক. 6√2
    • খ. 6√3
    • গ. 9√2
    • ঘ. 9√3
    উত্তর: গ. 9√2
    বর্গের চার বাহু সমান, তাই পরিসীমা = 4a = 36 থেকে বাহু a = 9 মিটার।
    বর্গের কর্ণ বাহুর সঙ্গে সমকোণী ত্রিভুজ তৈরি করে, তাই পিথাগোরাসের সূত্রে কর্ণ = √(a² + a²) = a√2 = 9√2 মিটার।
    মনে রাখুন: বর্গের কর্ণ বাহুর √2 গুণ, আর ক্ষেত্রফল = a² বা কর্ণ²/2। এখানে ক্ষেত্রফল 81 বর্গমিটার, আর (9√2)²/2 = 162/2 = 81, যা মিলে যায়।
  9. ২৩. কোনো সমবাহু ত্রিভুজের একটি বাহুকে উভয়দিকে সমান বর্ধিত করলে উৎপন্ন কোণদ্বয়ের বিয়োগফল কত?
    • ক. 0°
    • খ. 120°
    • গ. 180°
    • ঘ. 240°
    উত্তর: ক. 0°
    সমবাহু ত্রিভুজের প্রতিটি কোণ 60°। একটি বাহুকে উভয় দিকে বাড়ালে দুই প্রান্তে দুটি বহিঃস্থ কোণ হয়, যার প্রতিটি 180° - 60° = 120°।
    কোণ দুটি সমান, তাই তাদের বিয়োগফল 120° - 120° = 0°।
    মনে রাখুন: ত্রিভুজের বহিঃস্থ কোণ তার বিপরীত দুই অন্তঃস্থ কোণের যোগফলের সমান। সমবাহুতে এটি 60° + 60° = 120°। ত্রিভুজের তিন কোণের যোগফল সব সময় 180°।
  10. ৩২. বৃত্তের ব্যাস তিনগুণ বৃদ্ধি করলে বৃত্তের ক্ষেত্রফল কতগুণ বৃদ্ধি পাবে?
    • ক. ৩ গুণ
    • খ. ৯ গুণ
    • গ. ১৬ গুণ
    • ঘ. একটিও না
    উত্তর: খ. ৯ গুণ
    বৃত্তের ক্ষেত্রফল = πr²। ব্যাস তিনগুণ করলে ব্যাসার্ধও তিনগুণ হয়, কারণ ব্যাস = 2r। অর্থাৎ নতুন ব্যাসার্ধ 3r।
    নতুন ক্ষেত্রফল = π(3r)² = 9πr²
    অতএব ক্ষেত্রফল আগের ৯ গুণ হয়।
    মনে রাখুন: বৃত্তের ক্ষেত্রফল ব্যাসার্ধের বর্গের সমানুপাতিক, তাই ব্যাসার্ধ n গুণ হলে ক্ষেত্রফল n² গুণ হয়। পরিধি কিন্তু ব্যাসার্ধের সঙ্গে সরাসরি বাড়ে, অর্থাৎ ৩ গুণ হয়।
  11. ৪৪. একটি ত্রিভুজের তিনটি কোণের অনুপাত 3 : 4 : 5 হলে, ছোট কোণটি কত?
    • ক. 75°
    • খ. 60°
    • গ. 45°
    • ঘ. 30°
    উত্তর: গ. 45°
    ত্রিভুজের তিন কোণের সমষ্টি সব সময় 180°। কোণ তিনটির অনুপাত 3 : 4 : 5 হলে কোণগুলো 3x, 4x ও 5x ধরা যায়।
    3x + 4x + 5x = 180°
    বা, 12x = 180°
    বা, x = 15°
    ছোট কোণ = 3x = 3 × 15° = 45°। বাকি দুটি কোণ 60° ও 75°।
    মনে রাখুন: অনুপাত দেওয়া থাকলে প্রতিটি অংশ x দিয়ে ধরে নেওয়া সহজ। কোণগুলো সব সূক্ষ্মকোণ, তাই ত্রিভুজটি সূক্ষ্মকোণী।
  12. ৪৮. ত্রিভুজের একটি কোণ অপর দুই কোণের সমষ্টির সমান হলে ত্রিভুজটি—
    • ক. সূক্ষ্মকোণী
    • খ. সমকোণী
    • গ. সমবাহু
    • ঘ. স্থূলকোণী
    উত্তর: খ. সমকোণী
    ধরি ত্রিভুজের তিন কোণ A, B ও C এবং A = B + C। তিন কোণের সমষ্টি 180°, তাই A + B + C = 180°। এখানে B + C-এর জায়গায় A বসালে A + A = 180°, অর্থাৎ A = 90°। একটি কোণ 90° হলে ত্রিভুজটি সমকোণী।
    মনে রাখুন:
    সূক্ষ্মকোণী ত্রিভুজের তিনটি কোণই 90°-এর কম।
    স্থূলকোণী ত্রিভুজের একটি কোণ 90°-এর বেশি।
    সমবাহু ত্রিভুজের তিনটি কোণই 60°।
  13. ৫৪. কোনটি বৃহত্তম সংখ্যা?
    • ক. ৩/৮
    • খ. ৭/৮
    • গ. ৪/৫
    • ঘ. ৬/৭
    উত্তর: খ. ৭/৮
    ভগ্নাংশগুলোকে দশমিকে লিখে তুলনা করি:
    ৩/৮ = 0.375
    ৭/৮ = 0.875
    ৪/৫ = 0.8
    ৬/৭ ≈ 0.857
    সবচেয়ে বড় মান 0.875, তাই ৭/৮ বৃহত্তম।
    মনে রাখুন: দুটি ভগ্নাংশের আড়াআড়ি গুণ করে তুলনা করা যায়। যেমন ৭/৮ ও ৬/৭-এর জন্য ৭ × ৭ = ৪৯ এবং ৬ × ৮ = ৪৮, তাই ৭/৮ বড়। লব ও হরের পার্থক্য সমান (১) হলে লব-হর যত বড়, ভগ্নাংশ ১-এর তত কাছাকাছি ও বড়।
  14. ৫৫. secθ = 2 হলে, cotθ এর মান কত?
    • ক. 1/√5
    • খ. 1/√3
    • গ. √3
    • ঘ. √5
    উত্তর: খ. 1/√3
    secθ = 2 মানে 1/cosθ = 2, তাই cosθ = 1/2। আমরা জানি cos 60° = 1/2, সুতরাং θ = 60°।
    cotθ = cot 60° = 1/tan 60° = 1/√3।
    মনে রাখুন:
    sin 60° = √3/2, cos 60° = 1/2, tan 60° = √3।
    কোণ 30°, 45° ও 60°-এর মান মুখস্থ থাকলে এমন অঙ্ক দ্রুত হয়।
