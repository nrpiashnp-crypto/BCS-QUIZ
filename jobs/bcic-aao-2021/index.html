বিসিআইসি সহকারী প্রশাসনিক অফিসার নিয়োগ পরীক্ষা ২০২১: প্রশ্ন ও সমাধান

পরীক্ষা হয়েছে ১০ সেপ্টেম্বর ২০২১। ৬৫টি প্রশ্ন, সঠিক উত্তর আর প্রতিটির ব্যাখ্যা। চাইলে আগে নিজে পরীক্ষা দিয়ে দেখুন।

বাংলা

  1. ১. জিভের উচ্চতা অনুযায়ী নিম্ন-মধ্য স্বরধ্বনি কোনগুলো?
    • ক. অ, আ
    • খ. ই, উ
    • গ. এ, ও
    • ঘ. অ্যা, অ
    উত্তর: ঘ. অ্যা, অ

    উচ্চারণের সময় জিভের উচ্চতা অনুযায়ী স্বরধ্বনিকে উচ্চ, উচ্চ-মধ্য, নিম্ন-মধ্য আর নিম্ন—এ চার ভাগে ভাগ করা হয়। বাংলায় উচ্চ স্বর ই আর উ, উচ্চ-মধ্য এ আর ও, নিম্ন-মধ্য অ্যা আর অ, আর নিম্ন স্বর আ। তাই নিম্ন-মধ্য স্বরধ্বনি অ্যা আর অ।

  2. ২. কোনটি কণ্ঠনালীয় ব্যঞ্জনধ্বনি?
    • ক. ক
    • খ. শ
    • গ. ড়
    • ঘ. হ
    উত্তর: ঘ. হ

    'হ' কণ্ঠনালীয় বা স্বরতন্ত্রীয় ব্যঞ্জনধ্বনি, কারণ এটি উচ্চারণের সময় কণ্ঠনালীতে বাতাস ঘর্ষণ পেয়ে বের হয়। 'ক' জিভের পেছন দিয়ে নরম তালু স্পর্শ করে উচ্চারিত হয়, তাই কণ্ঠ্য বা জিহ্বামূলীয়। 'শ' তালব্য আর 'ড়' মূর্ধন্য তাড়নজাত ধ্বনি।

  3. ৩. ‘যুগ্ম’ শব্দের উচ্চারণ কোনটি?
    • ক. জুগানো
    • খ. জুগ্‌মো
    • গ. জুগ্‌মোঁ
    • ঘ. যুগনো
    উত্তর: খ. জুগ্‌মো

    'যুগ্ম' শব্দের উচ্চারণ 'জুগ্‌মো'। বাংলায় য-এর উচ্চারণ সাধারণত জ-এর মতো, আর শব্দের শেষের ম-এর সঙ্গে অ-কার ও-কারের মতো উচ্চারিত হয়। গ আর ম যুক্ত থাকায় মাঝে হসন্তের মতো বিরতি পড়ে। একই নিয়মে 'পদ্ম' উচ্চারিত হয় 'পদ্‌দোঁ'।

  4. ৪. বলকযুক্ত শব্দের উদাহরণ কোনটি?
    • ক. আকাশে
    • খ. যদিও
    • গ. চলন্ত
    • ঘ. বাতাস
    উত্তর: খ. যদিও

    প্রশ্নের চাবি অনুযায়ী 'যদিও' বলকযুক্ত শব্দের উদাহরণ। উচ্চারণে শব্দের কোনো অক্ষরে বাড়তি জোর বা ঝোঁক পড়াকে শ্বাসাঘাত বা বলক বলা হয়, আর বাংলায় সাধারণত শব্দের প্রথম অক্ষরে এ ঝোঁক পড়ে। এ ধরনের প্রশ্নে পাঠ্যবইয়ের নির্দিষ্ট উদাহরণ মনে রাখা ভালো।

  5. ৫. প্রত্যয় দিয়ে গঠিত হয়েছে কোন শব্দ?
    • ক. উত্তম
    • খ. চতুর্ভুজ
    • গ. স্বল্প
    • ঘ. দোকান
    উত্তর: ক. উত্তম

    'উত্তম' শব্দটি উৎ + তম প্রত্যয় যোগে গঠিত, অর্থ সর্বশ্রেষ্ঠ; 'তম' প্রত্যয় অতিশয় বা শ্রেষ্ঠত্ব বোঝায়, যেমন প্রিয়তম। 'চতুর্ভুজ' সমাসে গঠিত (চার ভুজের সমাহার), 'স্বল্প' উপসর্গযোগে (সু + অল্প), আর 'দোকান' ফারসি মৌলিক শব্দ।

  6. ৬. পরপদে বিশেষণ থাকে এবং পরপদের অর্থ প্রাধান্য পায় কোন সমাসে?
    • ক. উপমান কর্মধারয়
    • খ. উপমিত কর্মধারয়
    • গ. রূপক কর্মধারয়
    • ঘ. তৎপুরুষ
    উত্তর: ক. উপমান কর্মধারয়
    উপমান কর্মধারয়ে পূর্বপদে উপমান (বিশেষ্য) আর পরপদে সাধারণ ধর্মবাচক বিশেষণ থাকে, যেমন তুষারের ন্যায় শুভ্র = তুষারশুভ্র। কর্মধারয় সমাসে পরপদের অর্থই প্রধান।
  7. ৭. ‘বেগম’ শব্দটির উৎস কোন ভাষা?
    • ক. পর্তুগিজ
    • খ. তুর্কি
    • গ. ফারসি
    • ঘ. হিন্দি
    উত্তর: খ. তুর্কি

    'বেগম' তুর্কি ভাষা থেকে আসা শব্দ, অর্থ সম্ভ্রান্ত নারী বা রানি। তুর্কি থেকে আসা আরও শব্দ: বাবা, চাকু, কাঁচি, বন্দুক, দারোগা, বাবুর্চি, তোপ। মোগল আর তুর্কি শাসনামলে এসব শব্দ বাংলায় প্রবেশ করে।

  8. ৮. বহুবচনের যথার্থ প্রয়োগ ঘটেনি-
    • ক. কুসুমনিচয়
    • খ. পুষ্পদাম
    • গ. কুসুমদাম
    • ঘ. তারকাবলি
    উত্তর: ঘ. তারকাবলি
    নিচয় ও দাম বহুবচনবোধক শব্দ ফুলের সঙ্গে প্রচলিত (কুসুমনিচয়, পুষ্পদাম, কুসুমদাম)। তারার বহুবচনে প্রচলিত রূপ 'তারকারাজি' বা 'তারকাপুঞ্জ', তাই 'তারকাবলি'কে যথার্থ প্রয়োগ ধরা হয়নি।
  9. ৯. ‘কর’ ধাতুর পুরাঘটিত অতীত কালের প্রযোজক ক্রিয়ার উদাহরণ কোনটি?
    • ক. করেছিলে
    • খ. করতে
    • গ. করিয়েছিলাম
    • ঘ. করলাম
    উত্তর: গ. করিয়েছিলাম
    কর্তা নিজে না করে অন্যকে দিয়ে করালে প্রযোজক ক্রিয়া হয়। 'করিয়েছিলাম' মানে অন্যকে দিয়ে কাজটি আগে করানো হয়েছিল, তাই এটি পুরাঘটিত অতীতের প্রযোজক ক্রিয়া।
  10. ১০. ‘নাছোড়বান্দা’ অর্থ প্রকাশ করে কোন বাগধারাটি?
    • ক. মণিকাঞ্চন যোগ
    • খ. তীর্থের কাক
    • গ. চিনে জোঁক
    • ঘ. খয়ের খাঁ
    উত্তর: গ. চিনে জোঁক

    ‘চিনে জোঁক’ বাগধারার অর্থ নাছোড়বান্দা, অর্থাৎ যে একবার ধরলে সহজে ছাড়ে না, যেমন জোঁক গায়ে লেগে থাকে। বাকি বাগধারাগুলোর অর্থ আলাদা: খয়ের খাঁ মানে চাটুকার বা তোষামোদকারী, তীর্থের কাক মানে সাগ্রহে প্রতীক্ষাকারী, আর মণিকাঞ্চন যোগ মানে উপযুক্ত মিলন। তাই নাছোড়বান্দা ভাবের সঙ্গে কেবল চিনে জোঁক মেলে। যেমন: সে চিনে জোঁকের মতো পেছনে লেগে আছে।

  11. ১১. ‘বলাহক’ এর সমার্থক শব্দ কোনটি?
    • ক. রত্নাকর
    • খ. দ্বিরদ
    • গ. মৃগেন্দ্র
    • ঘ. জীমূত
    উত্তর: ঘ. জীমূত

    'বলাহক' মানে মেঘ, আর 'জীমূত'ও মেঘের প্রতিশব্দ; মেঘের আরও প্রতিশব্দ জলধর, নীরদ, বারিদ। 'রত্নাকর' মানে সমুদ্র, 'দ্বিরদ' মানে হাতি (দুটি দাঁত যার), আর 'মৃগেন্দ্র' মানে সিংহ।

  12. ১২. ‘লোকমুখে এই কথা শুনেছি’। কোন কারক?
    • ক. করণ
    • খ. কর্ম
    • গ. অপাদান
    • ঘ. অধিকরণ
    উত্তর: গ. অপাদান

    যা থেকে কিছু বিচ্যুত, গৃহীত, জাত বা শোনা হয়, তাকে অপাদান কারক বলে। 'লোকমুখে এই কথা শুনেছি' বাক্যে কথাটি লোকমুখ থেকে শোনা হয়েছে, তাই 'লোকমুখে' অপাদান কারক, আর 'এ' বিভক্তি থাকায় অপাদানে সপ্তমী। একই ধরনের উদাহরণ: 'বিপদে মোরে রক্ষা করো'।

  13. ১৩. মুসলিম সাহিত্য সমাজের মুখপত্রের নাম কী?
    • ক. মোসলেম ভারত
    • খ. মোহাম্মদী
    • গ. শিখা
    • ঘ. প্রগতি
    উত্তর: গ. শিখা

    ১৯২৬ সালে ঢাকায় প্রতিষ্ঠিত মুসলিম সাহিত্য সমাজের মুখপত্র ছিল 'শিখা' পত্রিকা, যা ১৯২৭ সালে প্রকাশ শুরু হয়। এ সংগঠন 'বুদ্ধির মুক্তি আন্দোলন' পরিচালনা করে, আর আবুল হুসেন, কাজী আবদুল ওদুদ, কাজী মোতাহার হোসেন এর নেতৃত্ব দেন। 'মোহাম্মদী' আর 'মোসলেম ভারত' ভিন্ন পত্রিকা।

  14. ১৪. ‘আমার ভাইয়ের রক্তে রাঙানো একুশে ফেব্রুয়ারি’ গানটি কোন সাহিত্য সংকলনে প্রথম প্রকাশিত হয়?
    • ক. নতুন কবিতা
    • খ. একুশে ফেব্রুয়ারি
    • গ. সুন্দরম
    • ঘ. কণ্ঠস্বর
    উত্তর: খ. একুশে ফেব্রুয়ারি

    আবদুল গাফফার চৌধুরীর লেখা 'আমার ভাইয়ের রক্তে রাঙানো একুশে ফেব্রুয়ারি' গানটি প্রথম প্রকাশিত হয় হাসান হাফিজুর রহমান সম্পাদিত 'একুশে ফেব্রুয়ারী' সংকলনে, ১৯৫৩ সালে। এটি ভাষা আন্দোলন নিয়ে প্রথম সাহিত্য সংকলন। গানটির বর্তমান সুর করেন আলতাফ মাহমুদ।

ইংরেজি

  1. ১৫. Fill in the blank: The authorities, fearing a ______ of their power, called for a military state in the hopes of restoring order.
    • ক. subversion
    • খ. premonition
    • গ. predilection
    • ঘ. infusion
    উত্তর: ক. subversion

    subversion মানে কর্তৃত্ব বা ব্যবস্থা উৎখাত বা দুর্বল করার চেষ্টা। বাক্যের অর্থ: কর্তৃপক্ষ নিজেদের ক্ষমতা উৎখাত হওয়ার ভয়ে শৃঙ্খলা ফেরানোর আশায় সামরিক শাসনের ডাক দেয়। premonition মানে পূর্বাভাস, predilection মানে পছন্দ, আর infusion মানে সঞ্চার।

  2. ১৬. Fill in the blank: Phillip's _____ tone endeared him to his comical friends, but irritated his serious father.
    • ক. aloof
    • খ. jesting
    • গ. grave
    • ঘ. earnest
    উত্তর: খ. jesting

    jesting মানে ঠাট্টাপূর্ণ বা রসিকতার। বাক্যের অর্থ: ফিলিপের রসিকতাপূর্ণ সুর তার মজার বন্ধুদের কাছে প্রিয় ছিল, কিন্তু গম্ভীর বাবাকে বিরক্ত করত। grave আর earnest মানে গুরুগম্ভীর, যা কৌতুকপ্রিয় বন্ধুদের সঙ্গে মেলে না; aloof মানে দূরত্ব বজায় রাখা।

  3. ১৭. Fill in the blank: Mary became ____ at typing because she practiced every day for six months.
    • ক. proficient
    • খ. reflective
    • গ. dormant

কম্পিউটার ও আইসিটি

  1. ৫৮. The volatile memory of a computer is known as?
    • ক. ROM
    • খ. BIOS
    • গ. RAM
    • ঘ. SSD
    উত্তর: গ. RAM

    কম্পিউটারের অস্থায়ী (volatile) মেমোরি হলো RAM, যেখানে বিদ্যুৎ বন্ধ হলে সব তথ্য মুছে যায়। ROM আর SSD স্থায়ী (non-volatile) মেমোরি, যেখানে বিদ্যুৎ ছাড়াও তথ্য থাকে। BIOS হলো ROM বা ফ্ল্যাশ মেমোরিতে রাখা কম্পিউটার চালু করার প্রোগ্রাম।

  2. ৫৯. Which of the following is used to transfer files?
    • ক. HTTP
    • খ. HTML
    • গ. IP
    • ঘ. FTP
    উত্তর: ঘ. FTP

    এফটিপি (FTP, File Transfer Protocol) হলো নেটওয়ার্কে এক কম্পিউটার থেকে আরেক কম্পিউটারে ফাইল পাঠানো ও নামানোর নিয়ম বা প্রটোকল। ওয়েবসাইটের ফাইল সার্ভারে তোলার কাজে এটি বহুদিন ধরে ব্যবহৃত হয়ে আসছে। অন্যদিকে এইচটিটিপি (HTTP) ওয়েবপেজ আনা-নেওয়ার প্রটোকল, এইচটিএমএল (HTML) ওয়েবপেজ তৈরির ভাষা আর আইপি (IP) নেটওয়ার্কে প্রতিটি যন্ত্রের ঠিকানা ঠিক করার প্রটোকল।

  3. ৬০. The machine-readable form of a program is called?
    • ক. Object code
    • খ. Source code
    • গ. Executable file
    • ঘ. None
    উত্তর: ক. Object code

    কম্পিউটার সরাসরি শুধু ০ ও ১-এর ভাষা বোঝে। এই ভাষার কোডকে object code বা machine code বলে, আর এটিই প্রোগ্রামের যন্ত্রপাঠযোগ্য রূপ। প্রোগ্রামার যে মূল কোড লেখেন, তাকে source code বলে। কম্পাইলার (Compiler) source code-কে object code-এ রূপান্তর করে, এরপর লিংক করে executable file তৈরি করা হয়।

  4. ৬১. A proxy server is used for which of the following?
    • ক. Provide security for unauthorized users.
    • খ. To process client requests for web pages.
    • গ. To process client requests for
    • ঘ. To process against virus
    উত্তর: খ. To process client requests for web pages.

    প্রক্সি সার্ভার (Proxy Server) ব্যবহারকারীর কম্পিউটার (Client) আর ইন্টারনেটের মাঝখানে বসে কাজ করে। ব্যবহারকারী কোনো ওয়েবপেজ চাইলে অনুরোধটি আগে প্রক্সি সার্ভারে যায়, সেটি মূল সার্ভার থেকে পেজটি এনে ব্যবহারকারীকে দেয়। তাই প্রক্সি সার্ভারের প্রধান কাজ ক্লায়েন্টের ওয়েবপেজের অনুরোধ প্রক্রিয়া করা। এর ফলে বারবার দেখা পেজ জমা (Cache) রেখে দ্রুত দেওয়া যায়, আর প্রতিষ্ঠানের ভেতরের কম্পিউটারগুলোর পরিচয়ও আড়ালে থাকে।
