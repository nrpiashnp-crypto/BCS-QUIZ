সম্মিলিত ৪ ব্যাংক ও আর্থিক প্রতিষ্ঠান আইটি-সংশ্লিষ্ট অফিসার (৩০ নভেম্বর) নিয়োগ পরীক্ষা ২০১৮: প্রশ্ন ও সমাধান

পরীক্ষা হয়েছে ৩০ নভেম্বর ২০১৮। ৮০টি প্রশ্ন, সঠিক উত্তর আর প্রতিটির ব্যাখ্যা। চাইলে আগে নিজে পরীক্ষা দিয়ে দেখুন।

ইংরেজি

  1. ১. He has no good cause ______ complaint. Darkness was the cause ______ his losing his way.
    • ক. for, of
    • খ. in, of
    • গ. at, in
    • ঘ. of, in
    উত্তর: ক. for, of
    'কোনো কিছুর যুক্তিসংগত কারণ বা ভিত্তি' বোঝাতে cause for, আর 'কোনো ঘটনা ঘটার কারণ' বোঝাতে cause of ব্যবহৃত হয়।
  2. ২. He agreed ______ my proposal. He agreed ______ me on that question. They could not agree ______ themselves.
    • ক. among, to, with
    • খ. for, about, in
    • গ. to, with, among
    • ঘ. in, to, by
    উত্তর: গ. to, with, among
    প্রস্তাব বা পরিকল্পনায় সম্মত হওয়া agree to, কোনো ব্যক্তির সঙ্গে একমত হওয়া agree with, আর নিজেদের মধ্যে একমত হওয়া agree among।
  3. ৩. Synonym of 'Fastidious'?
    • ক. Finicky
    • খ. Quarrelsome
    • গ. Meteoric
    • ঘ. Modulate
    উত্তর: ক. Finicky
    Fastidious মানে খুঁতখুঁতে, সহজে সন্তুষ্ট হয় না এমন; এর সমার্থক Finicky।
  4. ৪. Antonym of 'Myopia':
    • ক. Naïve
    • খ. Narcotic
    • গ. Farsighted
    • ঘ. Formidable
    উত্তর: গ. Farsighted
    Myopia মানে ক্ষীণদৃষ্টি বা দূরের জিনিস ঝাপসা দেখা (রূপক অর্থে অদূরদর্শিতা)। এর বিপরীত Farsighted, অর্থাৎ দূরদৃষ্টিসম্পন্ন।
  5. ৫. The timely rain _____ good crops.
    • ক. brings in
    • খ. brings about
    • গ. brings up
    • ঘ. brings forth
    উত্তর: ঘ. brings forth
    Bring forth মানে উৎপন্ন করা বা জন্ম দেওয়া। সময়মতো বৃষ্টি ভালো ফসল উৎপন্ন করে, তাই brings forth।
  6. ৬. What is the meaning of 'White Elephant'?
    • ক. A very costly or troublesome possession
    • খ. An elephant of white colour
    • গ. A black marketer
    • ঘ. A hoarder
    উত্তর: ক. A very costly or troublesome possession
    White elephant মানে এমন সম্পদ, যা রক্ষণাবেক্ষণে খরচ ও ঝামেলা বেশি কিন্তু উপকার সামান্য—বাংলায় যাকে বলে 'শ্বেতহস্তী পোষা'।
  7. ৭. Translate into English: চুন খেয়ে গাল পোড়ে, দই দেখলে ভয় করে।
    • ক. A still tongue makes a wise head.
    • খ. A scalded dog fears cold water.

    • ঘ. A pet lamb makes a cross ram
    উত্তর: খ. A scalded dog fears cold water.
    একবার বিপদে পড়লে মানুষ নিরীহ জিনিসেও ভয় পায়—এই ভাবের ইংরেজি প্রবাদ 'A scalded dog fears cold water' (গরম পানিতে পোড়া কুকুর ঠান্ডা পানিতেও ভয় পায়)।
  8. ৮. Choose the correct spelling:
    • ক. Seychcles
    • খ. Seychelles
    • গ. Sayshelles
    • ঘ. Sayshells
    উত্তর: খ. Seychelles
    সঠিক বানান Seychelles—ভারত মহাসাগরের একটি দ্বীপরাষ্ট্র।
  9. ৯. Choose the correct spelling:
    • ক. Reminisce
    • খ. Reminise
    • গ. Reminis
    • ঘ. Reminces
    উত্তর: ক. Reminisce
    সঠিক বানান Reminisce (sc দিয়ে), যার অর্থ স্মৃতিচারণ করা।
  10. ১০. 'In spite of all his brag he had to eat humble pie'. Choose the correct meaning of the idiom to eat humble pie.
    • ক. To force someone
    • খ. To yield under humiliating circumstances

    Eat humble pie মানে অপমানজনক অবস্থায় নত হওয়া বা ভুল স্বীকার করে নেওয়া। এত বড়াই করেও তাকে শেষে মাথা নোয়াতে হলো।

কম্পিউটার ও আইসিটি

  1. ১৭. Bitcoin uses _______ technology.
    • ক. P2P
    • খ. Neural
    • গ. AI
    • ঘ. Datamining
    উত্তর: ক. P2P
    বিটকয়েন কোনো কেন্দ্রীয় ব্যাংক ছাড়াই ব্যবহারকারীদের মধ্যে সরাসরি পিয়ার-টু-পিয়ার (P2P) নেটওয়ার্কে লেনদেন করে, যার হিসাব রাখে ব্লকচেইন।
  2. ৩১. Which operator is used to declare the destructor in C++?
    • ক. #
    • খ. ~
    • গ. @
    • ঘ. $
    উত্তর: খ. ~
    C++-এ ক্লাসের নামের আগে টিল্ডা (~) বসিয়ে ডেস্ট্রাক্টর ঘোষণা করা হয়, যেমন ~Car()।
  3. ৩২. Which alternative can replace the throw statement in C++?
    • ক. for
    • খ. break
    • গ. return
    • ঘ. exit
    উত্তর: গ. return
    throw-এর মতো return-ও ফাংশন থেকে তাৎক্ষণিকভাবে নিয়ন্ত্রণ ফিরিয়ে দেয়, তাই কোনো ত্রুটি জানাতে বিকল্প হিসেবে return (ত্রুটির কোড) ব্যবহার করা যায়।
  4. ৩৩. What type of reference should be used in vector arithmetic in C++?
    • ক. Dynamic
    • খ. Const
    • গ. both dynamic & const
    • ঘ. static
    উত্তর: খ. Const
    ভেক্টর যোগ-বিয়োগের অপারেটরে মূল ভেক্টর বদলানো উচিত নয়, আবার কপি করাও ব্যয়বহুল; তাই const reference ব্যবহার করা হয়।
  5. ৩৪. Which of these data types is used by operating system to manage the Recursion in Java?
    • ক. Array
    • খ. Stack
    • গ. Queue
    • ঘ. Tree
    উত্তর: খ. Stack
    প্রতিটি রিকার্সিভ কলের তথ্য কল স্ট্যাকে জমা হয় এবং শেষ কলটি আগে ফেরে (LIFO)। তাই রিকার্শন সামলাতে stack ব্যবহৃত হয়।
  6. ৩৫. Which of the following is an incorrect statement about packages?
    • ক. Package defines a namespace in which classes are stored
    • খ. A package can contain other packages within it
    • গ. Java uses file system directories to store packages
    • ঘ. A package can be renamed without renaming the directory in which the classes are stored.
    উত্তর: ঘ. A package can be renamed without renaming the directory in which the classes are stored.
    Java-তে package-এর নাম আর ডিরেক্টরির নাম মিলতে হয়। তাই ডিরেক্টরির নাম না বদলে package-এর নাম বদলানো যায় না—শেষ বিবৃতিটি ভুল।
  7. ৩৬. A derived class inherits attributes from a ______ .
    • ক. Super Class
    • খ. Sub Class
    • গ. Inner Class
    • ঘ. Upper Class
    উত্তর: ক. Super Class
    Inheritance-এ উদ্ভূত (derived) ক্লাস তার মূল বা super class থেকে বৈশিষ্ট্য ও মেথড উত্তরাধিকারসূত্রে পায়।
  8. ৩৭. Multiple inheritance in Java can be implemented using which of the following?
    • ক. Interfaces
    • খ. Multithreading
    • গ. Protected methods
    • ঘ. Private methods
    উত্তর: ক. Interfaces
    Java-তে একাধিক ক্লাস extend করা যায় না, কিন্তু একটি ক্লাস একাধিক interface implement করতে পারে। এভাবে multiple inheritance-এর সুবিধা পাওয়া যায়।
  9. ৩৮. Which component is used to compile, debug and execute java program?
    • ক. JVM
    • খ. JDK
    • গ. JIT
    • ঘ. JRE
    উত্তর: খ. JDK
    JDK (Java Development Kit)-এ কম্পাইলার (javac), ডিবাগারসহ উন্নয়নের সব টুল থাকে। JRE বা JVM শুধু প্রোগ্রাম চালায়।
  10. ৪০. Which of the following options is suitable, if A is '10110110', B is '11100000' and C is '10100000'?
    • ক. C = A or B
    • খ. C = A
    • গ. C = B
    • ঘ. C = A and B
    উত্তর: ঘ. C = A and B
    বিট ধরে AND করলে কেবল যেখানে দুটিতেই 1, সেখানে 1 হয়: 10110110 AND 11100000 = 10100000, যা C।
  11. ৪৪. The complexity of Binary search algorithm is -
    • ক. O(n)
    • খ. O(log n)
    • গ. O(n²)
    • ঘ. O(n log n)
    উত্তর: খ. O(log n)
    বাইনারি সার্চে প্রতি ধাপে সাজানো তালিকার অর্ধেক বাদ পড়ে, তাই n উপাদানে সর্বোচ্চ প্রায় $\log_2 n$ ধাপ লাগে—জটিলতা $O(\log n)$।
  12. ৪৫. A nonstandard HTML extension that causes scrolling text to appear as part of a Web page is:
    • ক. DHCP
    • খ. mask off
    • গ. Dhrystone
    • ঘ. marquee
    উত্তর: ঘ. marquee
    ট্যাগ দিয়ে ওয়েবপেজে লেখা চলমান বা স্ক্রল করানো যায়। এটি HTML-এর প্রমিত অংশ ছিল না, ব্রাউজারভিত্তিক বাড়তি সুবিধা।
  13. ৪৬. Object being passed to a copy constructor ____
    • ক. Must be passed by reference
    • খ. Must be passed by value
    • গ. Must be passed with integer type
    • ঘ. Must not be mentioned in parameter list
    উত্তর: ক. Must be passed by reference
    কপি কনস্ট্রাক্টরে অবজেক্ট by value পাঠালে সেটি কপি করতে আবার কপি কনস্ট্রাক্টর ডাকা হতো, ফলে অসীম পুনরাবৃত্তি ঘটত। তাই অবজেক্টকে অবশ্যই reference দিয়ে পাঠাতে হয়, যেমন Car(const Car &c); প্রদত্ত উত্তরটি তাই সংশোধন করা হয়েছে।
  14. ৪৭. Why do we need to handle exceptions?
    • ক. To prevent abnormal termination of program
    • খ. To encourage exception prone program
    • গ. To avoid syntax errors

    5. ৭৫. 'মস্যাধার' এর সঠিক সন্ধি বিচ্ছেদ হলো:

      • ঘ. মাছ + আধার
      উত্তর: খ. মসী + আধার
      'মসী' মানে কালি, আর 'আধার' মানে পাত্র। ঈ-এর পরে আ এলে ঈ য-ফলা হয়: মসী + আধার = মস্যাধার, অর্থাৎ দোয়াত।
