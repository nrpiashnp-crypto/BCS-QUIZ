    • ক. ৪ বছর
    • খ. ৮ বছর
    • গ. ৬ বছর
    • ঘ. ১২ বছর
    উত্তর: ক. ৪ বছর
    সরল মুনাফার সূত্রে মুনাফা = আসল × হার × সময়।
    4800 = 10000 × (12/100) × n
    4800 = 1200n
    n = 4
    তাই ৪ বছরে মুনাফা ৪৮০০ টাকা হবে।
    মনে রাখুন: ১০০০০ টাকার ১২% হারে ১ বছরের মুনাফা ১২০০ টাকা, আর ৪৮০০ হলো ১২০০-এর ঠিক ৪ গুণ।
  2. ২. log₁₀x = –2 হলে, x এর মান কত?
    • ক. .001
    • খ. 0.1
    • গ. .01
    • ঘ. 1.1
    উত্তর: গ. .01
    লগারিদমের সংজ্ঞা অনুযায়ী log_a x = n হলে x = aⁿ।
    log₁₀ x = −2 হলে x = 10⁻² = 1/100 = 0.01
    মনে রাখুন:
    log₁₀ 1 = 0, log₁₀ 10 = 1, log₁₀ 0.1 = −1, log₁₀ 0.001 = −3।
    যে সংখ্যা ১-এর চেয়ে ছোট, তার লগ সবসময় ঋণাত্মক হয়।
  3. ৩. (Y – 1) (Y + 2) = (Y + 4) (Y – 2) হলে, y এর মান কত?
    • ক. ৭
    • খ. ৬
    • গ. ১০
    • ঘ. ৩
    উত্তর: খ. ৬
    দুই পাশ গুণ করে খুলে লিখি।
    (y − 1)(y + 2) = y² + y − 2
    (y + 4)(y − 2) = y² + 2y − 8
    তাহলে y² + y − 2 = y² + 2y − 8
    y² দুই পাশ থেকে বাদ দিলে −2 + 8 = 2y − y, অর্থাৎ y = 6।
    যাচাই: (5)(8) = 40 এবং (10)(4) = 40, দুই পাশ সমান।
  4. ৪. একটি সরল রেখার উপর অঙ্কিত বর্গের ক্ষেত্রফল ঐ সরল রেখার এক-পঞ্চমাংশের উপরে অঙ্কিত বর্গের ক্ষেত্রফলের কতগুণ?
    • ক. ১৬
    • খ. ২৫
    • গ. ২২৫
    • ঘ. ১২৫
    উত্তর: খ. ২৫
    ধরি, রেখাটির দৈর্ঘ্য a। তাহলে এর এক-পঞ্চমাংশ a/5।
    পুরো রেখার ওপর বর্গের ক্ষেত্রফল = a²
    a/5-এর ওপর বর্গের ক্ষেত্রফল = a²/25
    অনুপাত = a² ÷ (a²/25) = 25
    তাই প্রথম বর্গটি দ্বিতীয়টির ২৫ গুণ।
    মনে রাখুন: দৈর্ঘ্য n গুণ হলে বর্গের ক্ষেত্রফল n² গুণ এবং ঘনকের আয়তন n³ গুণ হয়।

  6. ৬. একজন দোকানদার প্রতি হালি ডিম ২৫ টাকা দরে ক্রয় করে প্রতি ২ হালি ৫৬ টাকা দরে বিক্রয় করলে তার শতকরা কত টাকা লাভ হবে?
    • ক. ১০%
    • খ. ১২%
    • গ. ১৫%
    • ঘ. ১৮%
    উত্তর: খ. ১২%
    ১ হালি = ৪টি ডিম, তাই ২ হালি = ৮টি।

  7. ৭. A = {1,3,5} B = {5,7} হলে A ∩ B = কত?
    • ক. {5}
    • খ. {3,5,7}
    • গ. {7}
    • ঘ. {1,3,5,7}
    উত্তর: ক. {5}
    দুটি সেটের ছেদ (Intersection) মানে যে উপাদানগুলো দুই সেটেই আছে। A = {1, 3, 5} এবং B = {5, 7}-এর মধ্যে কেবল 5 দুই সেটেই আছে।
    A ∩ B = {5}
    মনে রাখুন: সংযোগ (Union) A ∪ B = {1, 3, 5, 7}, যেখানে দুই সেটের সব উপাদান একবার করে থাকে।
  8. ৮. P = {X:X, 2 এর গুণিতক এবং X ≤ 8} এবং Q = {X:X, 4 এর গুণিতক এবং X ≤ 12} হলে P ∩ Q = কত?

    • খ. {2,12}
    • গ. {4,8}
    • ঘ. {8,12}
    উত্তর: গ. {4,8}
    P হলো ৮ পর্যন্ত ২-এর গুণিতক, তাই P = {2, 4, 6, 8}। Q হলো ১২ পর্যন্ত ৪-এর গুণিতক, তাই Q = {4, 8, 12}।

    মনে রাখুন: ৪-এর প্রতিটি গুণিতকই ২-এরও গুণিতক, তাই ছেদ সেটে ৮-এর বেশি কোনো সংখ্যা আসবে না।

  14. ১৪. f(x) = x3 + kx2 . 6x - 9 ; k এর মান কত হলে f(3) = 0 হবে?

  16. ১৬. U = {1,2,3,4,5,6} এবং A = {2,4,6} হলে Aᶜ নির্ণয় কর?

    • খ. {1,3,5}
    • গ. {1,2,3,4,5,6}

    উত্তর: খ. {1,3,5}
    পূরক সেট (Complement set) Aᶜ মানে সার্বিক সেট U-এর যে উপাদানগুলো A-তে নেই। U = {1, 2, 3, 4, 5, 6} থেকে A = {2, 4, 6} বাদ দিলে থাকে {1, 3, 5}।
    Aᶜ = U − A = {1, 3, 5}
    মনে রাখুন: A ∪ Aᶜ = U এবং A ∩ Aᶜ = ∅।

    অন্য অপশনগুলো ঠিক নয়। প্রথম অপশনে দুটি বাক্য শুধু কমা দিয়ে জোড়া, কোনো সংযোজক নেই। দ্বিতীয় অপশনের অর্থ উল্টে গেছে, আর তৃতীয় অপশনটি সম্পূর্ণ বাক্যই হয়নি।
    মনে রাখুন:
    Simple বাক্যে একটি verb থাকে।
    Compound বাক্যে and/but দিয়ে জোড়া দুটি স্বাধীন বাক্য থাকে।
    Complex বাক্যে একটি স্বাধীন ও একটি অধীন বাক্য থাকে।
